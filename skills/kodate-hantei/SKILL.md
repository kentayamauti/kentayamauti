# 戸建投資 物件判定

持ち主の投資方針：戸建でリスク低く始める。地方の土地値は「願望」になりやすいので、
**最悪、更地で売っても損しない価格でしか買わない**。すでに1戸保有している。

## 手順

1. **物件情報を集める**
   - URL が渡されたらページを取得して読む。取得できない場合は、ページの文章コピーかスクショを貼ってもらう。
   - 抜き出す項目：価格（万円）、土地面積（㎡、坪は ×3.30579）、建物延床面積（㎡）、構造（木造／鉄骨／RC）、
     所在地、築年、接道（方位・公道/私道・幅員・間口）、境界（確定/明示の有無）、分筆の要否、
     現況または想定賃料、再建築不可・借地・市街化調整区域・私道負担・セットバック・告知事項・残置物の有無。
2. **前面路線価を決める**
   - 利用者が知っていればそれを使う。分からなければ、近隣の公示地価・基準地価（住宅地）を調べ、
     最寄り地点 × 0.8 を「推定路線価」として使い、推定であることを明記する。
     正確な値は全国地価マップ（https://www.chikamap.jp/）か国税庁の路線価図で確認するよう案内する。
3. **主要国道の交差点付近か判断する**
   - 国道2号・250号・29号・312号・43号や加古川バイパス・姫路バイパスなどの交差点から徒歩圏で、
     視認性があるかを地図で確認する。判断できなければ「該当しない」として保守的に扱う。
4. **家賃・リフォーム費を置く**
   - 賃料が資料になければ、周辺の戸建賃貸の相場から想定し、根拠を書く。リフォーム費は築年と状態から
     概算する（不明なら 150 万円）。どちらも仮置きであることを明記する。
5. **計算する**：`scripts/hantei.py` に JSON を渡して実行する（下の「計算ルール」と同じ式）。
   ```sh
   echo '{"price_man":480,"land_sqm":100,"rosenka":55000,"floor_sqm":82.5,"structure":"wood",
          "boundary":false,"rent_man":6,"reform_man":150}' | python3 scripts/hantei.py
   ```
6. **結論を書く**（下の「出力」）

## 計算ルール（ツールと同じ）

- 評価土地値 = 路線価 × 土地面積 × 掛け目
  - 主要国道の交差点付近：× 100%
  - 路線価 15万円/㎡ 超：÷ 0.8（時価目安）
  - 路線価 15万円/㎡ 以下：× 70%（「願望土地値」を割り引く）
- 実質土地値 = 評価土地値 − 解体費（延床 × 木造1.5万／鉄骨2.0万／RC2.8万 円/㎡）
  − 境界確定費（未確定なら40万円）− 分筆費用（必要なら30万円）− 売却時仲介手数料（(×3%+6万)×1.1）
- 購入総額 = 価格 × 1.07（諸費用：仲介手数料・登記・取得税など）+ リフォーム費
- 安全ライン = min( (実質土地値 − リフォーム費) ÷ 1.07, 年間家賃 ÷ 12% − リフォーム費 )
- 許容ライン = min( (実質土地値 + 5年分の手取り家賃 − リフォーム費) ÷ 1.07, 同上の利回り上限 )
  - 手取り家賃 = 年間家賃 × 80%（経費率20%）
- どちらも10万円単位で切り捨て
- 判定
  - **対象**：価格 ≦ 安全ライン
  - **条件付き**：安全ライン < 価格 ≦ 許容ライン（家賃回収込みで成立）
  - **指値次第**：価格 > 許容ライン（安全ラインまで、少なくとも許容ラインまで下がれば対象）
  - **対象外**：再建築不可、借地、または許容ラインが0以下

## 出力

最初に1行で結論を書く。例：「**指値次第**：320万円まで下がれば条件付きで対象、50万円なら安全圏」。
続けて次を短く並べる。

- 安全ライン・許容ラインと、今の価格からの指値額と指値率
- 実質土地値の内訳（評価土地値、解体費、境界・分筆、売却時仲介手数料）
- 表面利回り・実質利回り
- 立地とリスク：国道交差点との位置関係、ハザード（洪水・高潮・土砂）、接道、私道、境界、告知事項など
- 仮置きした数字（推定路線価、想定家賃、リフォーム費）と、確認すべきこと

指値率が30%を超えるときは「通りにくい指値」と添える。数値を決めつけず、仮置きの前提は必ず明示する。
