# 不動産物件選定相談所

物件を仲介・販売しない中立の立場で、物件選びを支援する相談所のランディングページです。

## 構成

- `index.html` — ページ本体（ヒーロー／お悩み／特徴／相談メニュー／物件選びチェック／流れ／料金／FAQ／予約フォーム）
- `css/style.css` — スタイル（レスポンシブ対応）
- `js/main.js` — モバイルメニュー、土地値判定シミュレーター、住所検索、買付前チェック、フォームの入力チェック
- `js/config.js` — 中継Worker のURL設定
- `worker/` — 不動産情報ライブラリ API の中継（Cloudflare Workers）

ビルド不要の静的サイトです。`index.html` をブラウザで開くか、GitHub Pages などで公開できます。

## 公開前に確認すること

- 予約フォームは現在ブラウザ上の入力チェックのみで、送信先がありません。Formspree などのフォームサービスやサーバーに接続してください。
- 料金・対応時間などは仮の内容です。実際のサービス内容に合わせて修正してください。
- 個人情報保護方針ページ・運営者情報（特定商取引法に基づく表記など）を追加してください。

## 住所からの自動取得（不動産情報ライブラリ API）

住所を入れて「調べる」を押すと、物件地点について次の情報を自動で取得します。

- 近隣の地価公示・地価調査（住宅地）と、そこから出した推定路線価（最寄り地点 × 0.8）
- 同じ地区（なければ市全体）の土地の取引・成約 ㎡単価と、戸建の価格の中央値
- 用途地域・建蔽率・容積率
- 洪水・高潮・津波・土砂災害の区域に入っているかどうか（該当すればシミュレーターの注意点にも表示）

APIキーをブラウザに出さないため、`worker/` の中継サーバーを経由します。

### セットアップ

1. 不動産情報ライブラリの API 利用申請をして、APIキーを受け取る
2. Cloudflare のアカウント（無料）を作り、`worker/` で次を実行する

   ```sh
   cd worker
   npx wrangler login
   npx wrangler secret put REINFOLIB_API_KEY   # 受け取ったAPIキーを貼り付け
   npx wrangler deploy                         # 表示された https://....workers.dev を控える
   ```

3. `js/config.js` の `apiBase` に、控えた Worker のURLを入れる
4. サイトを公開したら、`worker/wrangler.toml` の `ALLOWED_ORIGINS` にサイトのURLを入れて再デプロイする（他のサイトからキーを使われないようにするため）

動作確認：ブラウザで `https://....workers.dev/lookup?lat=34.7568&lon=134.8414` を開き、JSON が返れば成功です。

テスト：`cd worker && npm test`（API応答を模したテスト。実APIは使いません）
