# 不動産物件選定相談所

物件を仲介・販売しない中立の立場で、物件選びを支援する相談所のランディングページです。

## 構成

- `index.html` — ページ本体（ヒーロー／お悩み／特徴／相談メニュー／物件選びチェック／流れ／料金／FAQ／予約フォーム）
- `css/style.css` — スタイル（レスポンシブ対応）
- `js/main.js` — モバイルメニュー、物件選びチェック（自己診断）、フォームの入力チェック

ビルド不要の静的サイトです。`index.html` をブラウザで開くか、GitHub Pages などで公開できます。

## 公開前に確認すること

- 予約フォームは現在ブラウザ上の入力チェックのみで、送信先がありません。Formspree などのフォームサービスやサーバーに接続してください。
- 料金・対応時間などは仮の内容です。実際のサービス内容に合わせて修正してください。
- 個人情報保護方針ページ・運営者情報（特定商取引法に基づく表記など）を追加してください。
